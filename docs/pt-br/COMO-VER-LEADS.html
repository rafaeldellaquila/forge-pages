Como ver os leads no Supabase

Um passo a passo simples para acompanhar os contatos que chegam pelas landing pages — sem precisar de conhecimento técnico.

O que é um lead

Um lead é um contato interessado que preencheu o formulário em uma das landing pages — nome, WhatsApp, e-mail, mensagem. O caminho é sempre o mesmo:

Visitante preenche o formulário na página
→ o sistema confere que não é um robô
→ o contato é salvo com segurança no banco de dados
→ fica disponível para consulta, separado por cliente

Não existe hoje um painel próprio para leads — eles ficam guardados no Supabase, a mesma ferramenta usada para editar o conteúdo das páginas.

Antes de começar: o acesso

Como pedir acesso

Quem já tem acesso ao Supabase precisa te adicionar como membro do projeto pelo painel. Depois de aceitar o convite, você entra pelo navegador, sem instalar nada: supabase.com/dashboard → projeto da Forge Company.

Atenção

Esse convite dá acesso a todo o projeto, não só à lista de leads — hoje não existe uma forma de liberar visão só dos contatos. Trate o acesso como pessoal e não compartilhe seu login.

Encontrando os leads

Entre no painel

Acesse supabase.com/dashboard e faça login.

Abra o projeto

Selecione o projeto da Forge Company na lista.

Table Editor

No menu à esquerda, clique em Table Editor.

Tabela leads

Na lista de tabelas, clique em leads. Cada linha é um contato recebido.

O que cada coluna significa

ColunaO que é
nameNome informado pelo contato
whatsappWhatsApp informado
emailE-mail informado (pode estar vazio)
messageMensagem escrita pela pessoa (pode estar vazia)
intentO interesse selecionado no formulário
domainDe qual landing page veio o contato
statusEm que ponto do atendimento o lead está
created_atData e hora em que o contato chegou
utm_source/medium/campaignDe onde veio o clique, se por anúncio/campanha

Filtrar, ordenar e exportar

Filtrar por cliente: clique em Filter → coluna domain → digite o domínio. Filtrar por status: mesma ideia, na coluna status. Mais recentes primeiro: a coluna created_at já vem ordenada assim por padrão.

Para gerar uma planilha com o que está filtrado na tela, use o botão de exportar (ícone de download, ao lado de Filter) — baixa um CSV.

Cuidado com o CSV

O arquivo exportado contém dados pessoais (nome, WhatsApp, e-mail). Não reenvie por canais abertos e apague quando não precisar mais dele.

Atualizando o andamento de um contato

A coluna status é editada direto na mesma tabela — clique duas vezes na célula e escolha um valor. Manter isso atualizado é o que permite, no futuro, saber quantos leads viraram cliente de fato.

new — recém-chegado contacted — já falamos converted — virou cliente lost — não seguiu

Resumo rápido

  1. 01 Pedir convite de acesso ao Supabase.
  2. 02 Table Editor → tabela leads.
  3. 03 Filtrar por domain e/ou status.
  4. 04 Exportar em CSV se precisar de planilha.
  5. 05 Atualizar status conforme for atendendo cada contato.
