Landing Page Creation — Technical Walkthrough

How a tenant's page comes to exist: the data model, the request path that resolves it, and the block system that becomes its content. Companion to docs/ADD_CLIENT.md, not a replacement for it.

The data model

One client can eventually own more than one domain; today every seeded tenant has exactly one.

Request → tenant resolution

The middleware never queries Supabase — it only resolves which hostname to look up. One cached query in the Server Component serves both layout and page (ADR-0008).

The 11 block types

Each has a TypeScript interface (lib/types/blocks.ts) and a matching Zod schema (lib/schemas/blocks.ts). Full field tables: .claude/rules/blocks.md.

headerlogo, menu, CTA
heroheadline, primary/secondary CTA
trust-iconsicon + text items
statsnumber + label items
value-propositioneyebrow, cards
servicestabs, client-side state
differentialstagged items
testimonialsname, role, rating
cta-formthe lead form itself
pricingplans, features, featured flag
footerlinks, phones, socials
